*[irrep]: Irreducible representation — one fundamental symmetry species (row) of a character table. See the Glossary.
*[irreps]: Irreducible representations — the fundamental symmetry species (rows) of a character table. See the Glossary.
*[Schoenflies]: The point-group notation pyrrhotite uses (C2v, D6h, Td, …), common in chemistry. See the Glossary.
*[Hermann–Mauguin]: The crystallographic "international" symmetry notation — pyrrhotite does not use it. See the Glossary.
*[improper rotation]: A rotation by 360°/n followed by a reflection through the perpendicular plane (an Sn operation). See the Glossary.
*[conjugacy class]: A set of symmetry operations equivalent under the group's own symmetry; one character-table column per class. See the Glossary.
